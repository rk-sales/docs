## Частые вопросы {: #faq }

<div class="halva-faq">
<details class="halva-faq__item" open>
<summary>Что такое карта «Халва» и как она работает?</summary>
<div class="halva-faq__answer">
<p>Карта «Халва» от Совкомбанка — это карта рассрочки. Покупатель оплачивает товар, как обычной картой, но сумма делится на равные платежи без процентов при соблюдении срока рассрочки. Магазин получает всю сумму сразу.</p>
</div>
</details>
<details class="halva-faq__item">
<summary>Что даёт подписка «Халва.Десятка»?</summary>
<div class="halva-faq__answer">
<p>С подпиской срок рассрочки у партнёров увеличивается до 10 месяцев, а кэшбэк за покупки может достигать 10%. Все условия клиент видит до подтверждения покупки.</p>
</div>
</details>
<details class="halva-faq__item">
<summary>Нужно ли магазину ждать оплату от клиента?</summary>
<div class="halva-faq__answer">
<p>Нет. Совкомбанк оплачивает заказ магазину полностью сразу после оформления. Все дальнейшие платежи клиента — это отношения между клиентом и банком.</p>
</div>
</details>
<details class="halva-faq__item">
<summary>Какие риски несёт магазин?</summary>
<div class="halva-faq__answer">
<p>Магазин не несёт кредитных рисков. Просрочки и взыскание задолженности лежат на банке.</p>
</div>
</details>
<details class="halva-faq__item">
<summary>Как подключить оплату картой «Халва»?</summary>
<div class="halva-faq__answer">
<p>Оплата через карту «Халва» подключается автоматически после активации магазина в ЛК Robokassa.</p>
</div>
</details>

<script>
(function () {
  const page = document.querySelector('.halva-page');
  if (!page) return;

  const card = page.querySelector('.halva-card');
  const dots = page.querySelectorAll('.halva-card-switcher__dot');

  const accents = {
    white: { accent: '#ff3b7f', dark: '#e62e6b', soft: '#fff0f5' },
    black: { accent: '#ff3b7f', dark: '#e62e6b', soft: '#fff0f5' },
    'black-pink': { accent: '#ff3b7f', dark: '#e62e6b', soft: '#fff0f5' },
    gradient: { accent: '#8b5cf6', dark: '#7c3aed', soft: '#f3e8ff' }
  };

  function setDesign(design) {
    card.dataset.design = design;
    const a = accents[design] || accents['black-pink'];
    page.style.setProperty('--halva-accent', a.accent);
    page.style.setProperty('--halva-accent-dark', a.dark);
    page.style.setProperty('--halva-accent-soft', a.soft);

    dots.forEach(d => d.classList.toggle('halva-card-switcher__dot--active', d.dataset.design === design));
  }

  dots.forEach(dot => {
    dot.addEventListener('click', () => setDesign(dot.dataset.design));
  });

  card.addEventListener('click', () => {
    const order = ['white', 'black', 'black-pink', 'gradient'];
    const current = card.dataset.design;
    const next = order[(order.indexOf(current) + 1) % order.length];
    setDesign(next);
  });
})();
</script>
