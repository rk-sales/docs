## Вопросы и ответы {: #faq }

<div class="evotor-section-subtitle">Ответы на частые вопросы</div>

<details class="evotor-question"><summary>Подходит ли это решение для физических смарт-терминалов Эвотор?</summary><div class="evotor-question__content"><p>Да. Если у вас есть смарт-терминал Эвотор, в его личном кабинете (в разделе «Мои покупки» → «Цифровая касса» → «Настройки») можно найти данные для интеграции. Также для корректной работы должно быть установлено приложение «Цифровая касса».</p></div></details>

<details class="evotor-question"><summary>Где взять ID группы ККТ?</summary><div class="evotor-question__content"><p>Этот идентификатор находится в личном кабинете Эвотор (в карточке кассы или в настройках приложения «Цифровая касса»). Он представляет собой уникальный код группы ваших касс.</p></div></details>

<details class="evotor-question"><summary>Нужно ли покупать кассу?</summary><div class="evotor-question__content"><p>Нет. Если вы уже арендуете облачную кассу в Эвотор или используете их смарт-терминал, покупать ничего не нужно. Вы просто подключаете к ней эквайринг Robokassa для приёма онлайн-платежей.</p></div></details>
