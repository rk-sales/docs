## 5. Проверка работоспособности {: #check }

<div class="atol-steps-guide">
<div class="atol-guide-step">
<div class="atol-guide-text">
<div class="atol-step-heading">Проверка чека</div>
<p>Проведите тестовый платёж на небольшую сумму через магазин, для которого настроена интеграция.</p>
<p>Убедитесь, что:</p>
<ul style="margin-top: 10px; margin-bottom: 10px; padding-left: 20px; font-size: 1.05rem; color: var(--atol-text);">
<li>ваша касса (или облачный сервис АТОЛ) пробила чек;</li>
<li>в разделе операций в ЛК Robokassa у платежа есть <b>фискальный чек</b> (или ссылка на него);</li>
<li>покупателю пришёл чек на e‑mail/SMS.</li>
</ul>
<p>Если чек не сформировался, проверьте настройки в ЛК АТОЛ и корректность введённых данных.</p>
