## О Robokassa {: #about-robokassa }

<div class="hero-card">
  <div class="hero-content">
    <p><strong>Robokassa</strong> — это сервис для приёма онлайн-платежей на сайте, в мобильном приложении или через мессенджеры. Мы обеспечиваем безопасность транзакций, автоматическую фискализацию по 54-ФЗ и поддерживаем все популярные способы оплаты.</p>
